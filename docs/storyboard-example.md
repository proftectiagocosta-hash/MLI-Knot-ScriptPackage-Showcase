# Storyboard example

This document shows a fictional storyboard derived from a sanitized ScriptPackage.

---

## Example topic

Topic: A short educational video explaining why clear project documentation matters.

This is fictional and public-safe.

---

## Scene 1

Title: The messy start

Visual idea: A desk with scattered notes, windows open, and unclear filenames.

Narration: Every project starts with energy, but without structure, the next step becomes harder to find.

On-screen text: Projects need memory.

---

## Scene 2

Title: The structure appears

Visual idea: Notes become organized into folders, sections, and a clear README.

Narration: A simple structure can turn scattered progress into something reusable.

On-screen text: Organize before scaling.

---

## Scene 3

Title: The reusable package

Visual idea: A clean package card with title, hook, scenes, caption, and metadata.

Narration: A ScriptPackage is an intermediate layer between idea and output.

On-screen text: Idea -> package -> output.

---

## Scene 4

Title: The safe showcase

Visual idea: Public documentation separated from private source material.

Narration: Public showcases should explain the concept without exposing private work.

On-screen text: Public, sanitized, useful.
