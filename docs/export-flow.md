# Export flow

This document explains the public concept of exporting from a ScriptPackage.

---

## Main flow

prompt -> ScriptPackage v0.1 -> review -> export files

---

## Possible export files

A private prototype may export files such as:

- scriptpackage-v0.1.json;
- scriptpackage-v0.1.md;
- storyboard.txt;
- storyboard.html;
- manifest.json;
- video file;
- audio file.

This showcase does not include real private exported packages.

---

## JSON export

The JSON export is useful for structured reading, validation, and future automation.

---

## Markdown export

The Markdown export is useful for human review, documentation, and manual editing.

---

## Storyboard export

The storyboard export is useful for reviewing the sequence of scenes before producing or editing video material.

---

## Manifest

A manifest can describe which files were generated and whether the package appears complete.

---

## Public boundary

Public examples must be fictional and sanitized.

Do not publish real exports without review.
