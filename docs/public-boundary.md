# Public boundary

This document defines the safe public boundary for the MLI-Knot ScriptPackage Showcase.

---

## Allowed here

This repository may include:

- public documentation;
- fictional examples;
- sanitized package structures;
- conceptual diagrams;
- public-safe storyboard examples;
- explanations of current limits.

---

## Not allowed here

This repository must not include:

- private source code from MLI-Knot Video Forge Lite;
- real exported packages;
- private prompts;
- personal data;
- credentials;
- internal logs;
- unrevised development notes;
- real outputs that were not reviewed for public release.

---

## Review rule

Before adding anything here, check whether it is:

public
sanitized
fictional when needed
safe to share
useful for explaining ScriptPackage

If there is doubt, keep it private.
